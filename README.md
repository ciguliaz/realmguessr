# RealmGuessr 🗺️

An open-world 3D video game GeoGuessr platform. Explore 360° in-game panoramic captures and pinpoint your location on an interactive 3D terrain map.

## Tech Stack
- **Engine:** [Babylon.js](https://www.babylonjs.com/) (WebGPU/WebGL 3D terrain & 360° PhotoDome)
- **Tooling:** [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)

## Supported Games
- **The Elder Scrolls V: Skyrim** *(Primary)*
- Designed to be modular and easily extended to other open-world games (Elden Ring, GTA V, etc.).

## Setup & Development
```bash
npm install
npm run dev
```
